# vihomeweb

## 🏗️ Descripción del Proyecto

**vihomeweb** es una aplicación web construida con **Flutter (Web)**, diseñada para ser la plataforma central de administración y gestión en el sector inmobiliario colombiano.

**Objetivo Principal:** Servir como un sistema robusto que permite a las empresas administrar proyectos completos de construcción e inversión. Su enfoque va más allá de ser solo un portal de ventas; es una herramienta de gestión integral que rastrea propiedades o complejos desde su etapa inicial hasta la posventa.

**Funcionalidades Clave:**
*   **Gestión de Proyectos:** Seguimiento detallado de proyectos inmobiliarios en diferentes fases (Construcción, Venta, Posventa).
*   **Registro de Constructoras:** Mantiene un directorio centralizado y base de datos actualizable de empresas constructoras activas en el mercado colombiano.
*   **Administración Centralizada:** Proporciona una vista holística del ciclo de vida del desarrollo inmobiliario.

**Arquitectura:** El proyecto se desarrollará siguiendo los principios de **Arquitectura Limpia (Clean Architecture)** para asegurar que la base de datos, la lógica de negocio y la interfaz web sean escalables, mantenibles y fáciles de testear.
